# PCDN 屏蔽

[功能目录](README.md) · [项目首页](../../README.md)

### 勾选的含义与优先级

**勾选“阻止…”表示阻止命中的地址，取消表示不按该项阻止。** 只有来源策略选择“屏蔽 PCDN”时，这些规则才生效。域名类规则还受“启用域名屏蔽规则”控制，参数、路径和 IP 条件不受这个域名子开关控制。

判断顺序为：

1. 来源策略不是“屏蔽 PCDN”：不按 PCDN 策略阻止。
2. 命中域名放行：不按 PCDN 策略阻止。
3. 检查启用的规则：任意一项命中即阻止。
4. 未命中：不按 PCDN 策略阻止。

规则采用“任意命中”是为了让不同线索各自生效。例如一个地址同时属于 mcdn 域名且带有 `os=mcdn`，只取消域名规则仍会被参数规则阻止。需要允许整个域名时，可使用域名放行，或关闭所有相关命中项。

PCDN 放行优先于 PCDN 屏蔽规则，但不取消签名、Range 等传输校验。节点优选是另一种互斥来源策略，不使用这份放行列表；该策略下最终重定向至未选域名或 `/v数字/` 专用路径仍会被拒绝。

## 各项域名规则

下列规则各有独立开关，初始均勾选；只有来源策略为“屏蔽 PCDN”且域名规则子开关开启时才生效。

| 规则 | 匹配范围 | 判断理由 |
| --- | --- | --- |
| 阻止 mcdn 域名 | `mcdn.bilivideo.com`、`.cn`、`.net` 及各自子域名 | mcdn 分发体系的域名线索 |
| 阻止 szbdyd 域名 | `szbdyd.com` 及子域名 | 历史 PCDN 地址体系的域名线索 |
| 阻止 nexusedgeio 域名 | `nexusedgeio.com` 及子域名 | PCDN 分发及调度落点的域名线索 |
| 阻止七牛 PCDN 域名 | `ahdohpiechei.com` 及子域名 | 七牛 PCDN 的域名线索 |
| 阻止 mountaintoys 域名 | `mountaintoys.cn` 及子域名 | 覆盖 `edge.mountaintoys.cn` 等分发地址 |

匹配使用完整域名或带点的子域名边界。例如 `a.edge.mountaintoys.cn` 命中，`evil-mountaintoys.cn` 不命中。域名规则是可配置的来源分类线索，不是对该域名每一次请求均发生 P2P 传输的检测证明。

## 其他判断条件

| 规则 | 条件 | 默认勾选 | 判断理由与取舍 |
| --- | --- | --- | --- |
| 阻止 os=mcdn 地址 | 查询参数 `os` 的值等于 `mcdn` | 是 | 即使域名看起来像普通 Mirror，参数仍可能标识 mcdn 分发 |
| 阻止 302 调度域名 | 域名第一段包含 `302` | 是 | 识别常见调度域名命名；并非见到任何 HTTP 302 状态码就阻止 |
| 阻止 resource 路径 | 路径匹配 `/v数字/resource/` | 是 | 识别专用资源地址，包含 `/v1/resource/`；路径也影响地址能否迁移 |
| 阻止符合条件的 IP 地址 | IP 主机名，同时具有显式非默认端口或上述 resource 路径 | 否 | IP 本身不足以认定 PCDN，附加条件用于缩小范围，且默认不启用 |

这些条件是独立的启发式策略。规则开关允许用户按实际网络情况调整，程序不会将所有 IP、非默认端口或重定向一律等同于 PCDN。

## 域名放行

放行项可用空格、换行、逗号或分号分隔：

```text
node.mcdn.bilivideo.cn
*.mountaintoys.cn
```

精确项只匹配该域名自身；`*.example.com` 匹配子域名，不包含根域名 `example.com`。需要根域名和子域名都允许时，分别填写两项。放行匹配不区分大小写，不接受任意正则表达式。

本功能限制媒体来源，不替换或锁定页面 P2P SDK，因此关闭屏蔽不需要恢复一个已被全局替换的 SDK；相应地，也不承诺从浏览器层面禁用所有页面 P2P 行为。
