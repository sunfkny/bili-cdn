# 节点优选

[功能目录](README.md) · [项目首页](../../README.md)

通过运营商、地区或单节点选择播放所用 CDN；默认节点、空选语义与来源策略组合见[下载来源策略](source-policy.md)。节点优选中的达标筛选方式见[CDN 测速](benchmark.md)。

## CDN 候选与地址迁移

候选由播放器当前请求地址、媒体登记的主备地址，以及允许迁移到所选节点的地址组成。关闭 CDN 选择时，不额外引入一组隐藏的种子节点。

地址迁移保留文件路径与查询参数，包括播放接口给出的签名；仅当路径以 `/upgcxcode/` 开头时生成其他 Host 的候选。专用路径中偶然包含这一字符串也不能据此迁移。这一类 UPOS 地址在兼容节点间通常可以共用路径和签名，但仍需实际请求验证节点是否有文件、签名是否被接受以及 Range 是否有效。

有两类地址不直接换 Host：

- `/v1/resource/` 等专用路径：它们不是普通 UPOS 文件路径，改域名并不能把专用资源映射为另一个节点上的同一文件。
- Akamai 地址：其令牌与分发体系不同，不能假设它接受其他 UPOS 节点的签名，也不能把 Akamai 自己的签名移到其他节点。

手选 CDN 的候选会剔除 `/v数字/` 专用路径，即使接口把这种路径与已选 Host 一起返回，也不会用于普通 CDN 请求。请求路由还会拒绝已选 Host 上的这类无效地址，或在已登记的同一媒体文件中选择真正可用的普通地址；不会把 `/v1/` 改成另一种路径来猜测文件位置。测速也只采用可迁移的普通 UPOS 文件地址。

允许某个 PCDN 域名，只表示不因 PCDN 规则过滤它，不表示其地址可以迁移或必然支持分片。

候选会检查签名有效期；有已知过期时间时，剩余时间需超过 60 秒，减少传输过程中签名失效的概率。域名放行不会取消有效期、节点可用性与传输校验。
